# 게임 워크스페이스의 3D 레퍼런스와 라이선스

확인일: 2026-11-08. 공식 저장소 파일은 GitHub API 트리와 고정된 커밋의 원문으로 확인했다. 로컬 상태는 설치 파일과 실행기, 워크스페이스 코드를 확인했다. 이 기록은 확인 범위와 현재 적용 상태이지 포괄적인 권리 보증이나 법률 의견은 아니다.

## 현재 워크스페이스 상태

게임 씬 제작기인 `studio`는 설치된 제작기를 호출하고 결과와 게임 씬 배치를 소유한다. `studio/tools/scene.py`는 `pixel-effect`와 `model-assets` 생산자를 선택하고, 3D 결과에는 성공한 검증과 `.glb` 산출물을 요구한다. 워크스페이스 진행 기록은 Model Assets 0.1.0의 Blender 5.2.1 → Webstage 1.0.0 hero → Three.js 0.187.0 제작·검증, 30cm 등불의 Blender 재임포트, 실제 GLB의 로컬 WebGL 브라우저 렌더를 보고한다. 측정값과 검토 캡처는 [워크스페이스 진행 기록](../../PROGRESS.md), [브라우저 검증 데이터](../../examples/forest-camp/evidence/glb-browser.json), [화면 캡처](../../examples/forest-camp/evidence/glb-browser.jpg)에 연결했다. 이 증거는 Model Assets 제작과 브라우저 렌더를 확인하지만, `studio/tools/scene.py`의 전체 headless 씬 빌드나 게임 런타임 엔진 임포트·플레이 수락까지 증명하지는 않는다.

검토한 외부 레퍼런스에서 스킬 본문, 코드, 이미지, 모델 또는 폰트를 복사한 파일은 없다. 아래의 “반영”은 현재 코드에서 확인 가능한 설계 방향만을 뜻한다.

Model Assets가 Python으로 Blender 스크립트를 시작하고 Node로 Three 검사를 실행한다. 설치된 Python에는 `lib/python3.13/LICENSE.txt`, Node에는 배포본 루트 `LICENSE` 파일이 있으며 Node LICENSE 안에는 제3자 고지도 포함된다. Python 공식 [법률 안내](https://www.python.org/about/legal/)는 Python 및 표준 라이브러리가 Python License로 배포됨을 알린다. | 현재 설치 환경의 실행기이며 게임 GLB 결과에 포함되지 않는다. 앱에 실행기를 번들하는 경우 배포한 정확한 Python/Node 빌드의 라이선스·제3자 고지를 해당 실행기 배포자가 확인해 제공해야 한다. 이 조사에서는 전체 설치본의 모든 전이 패키지·시스템 라이브러리를 감사하지 않았다. |

모델 제작기 플러그인 자체의 소스 라이선스, 모든 실행기/Node 전이 의존성의 완전한 라이선스 목록, 게임 런타임의 3D 엔진·실제 배포 패키지는 현재 확인되지 않았다. 따라서 이 문서는 상용 배포 가능성에 대한 일괄 승인으로 사용하지 않는다. 실제 GLB를 게임에 채택하거나 Blender/Node/Three 코드를 앱에 동봉할 때 해당 파일과 정확한 실행 환경을 기준으로 고지 기록을 보완해야 한다.

후속 설치본과 프로젝트 실행 결과는 [검증 기록](../../PROGRESS.md)에 있다. 위 0.1.0 경로는 조사 당시의 기준이다. 새 3D 씬은 Blender 불티 메시를 등불에 부착하고 Three.js 인스턴스 변환으로 재생한다. 이전 2D·3D 혼합 검증 실행도 그래프에 남는다.
