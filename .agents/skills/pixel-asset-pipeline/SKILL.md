name: pixel-asset-pipeline
description: 게임에 쓸 2D 픽셀 캐릭터·아이콘·아이템을 만들거나 같은 스타일로 수정할 때 사용한다. 장비 교체, 포즈 시트, 반복 지형, 6동작 캐릭터와 타격·수집·불꽃 효과를 제작하고 원본 크기에서 비교·검수한다.
---

게임 호스트에 넘길 PNG와 임포트 정보를 납품한다. 먼저 프로젝트에서 승인한 기준 그림, 팔레트, 원본 크기, 시점과 피벗을 확인한다. 수정 요청이면 바꿀 부분과 유지할 부분을 정한다. 보호할 얼굴·몸·발선이 있는 캐릭터에는 원본 격자를 유지한다.

| 명령 | 어떤 요청에 쓰는지 |
| --- | --- |
| `build` | 새 캐릭터·아이콘·아이템을 만들거나 로컬 초안을 최종 PNG 규격으로 정리한다. |
| `validate` | 기존 정적 PNG의 크기·팔레트·투명도·기준선을 파일 변경 없이 검사한다. |
| `variant` | 승인된 몸에 등불이나 지팡이 등 장비만 교체한다. 손 부착점과 가림 허용 영역을 지정한다. |
| `compare` | 같은 게임에 속한 정적 번들과 기준 그림을 같은 피벗에 놓고 1×와 4×로 비교한다. |
| `sheet` | 실제로 그린 포즈를 동일 격자·공통 피벗·프레임별 재생 시간으로 묶는다. |
| `tile` | 가장자리까지 채운 불투명 지형의 팔레트와 반복 이음새를 검사한다. |
| `action-set` | 대기·걷기·달리기·공격·점프·피격의 로컬 포즈를 한 캐릭터 아틀라스로 묶고, 접촉 프레임에 pixelfx의 로컬 효과를 연결한다. |
| `effect` | 픽셀 코드로 수집 반짝임 또는 반복 불꽃을 만든다. 색과 시드로 변형한다. |

[제작 계약과 실행 예시](references/production.md)에서 선택한 명령의 입력을 확인한다. 설치본에서는 이 파일의 상위 네 디렉터리가 플러그인 루트다. 준비된 Python 3.10 이상·Pillow 10~12 환경에서 `PYTHONPATH="$PLUGIN_ROOT/src" "$PYTHON" -m pixel_asset_pipeline.cli`를 문서의 `pixel-asset` 대신 사용할 수 있다. 이렇게 하면 읽고 있는 스킬과 같은 배포본의 제작 코드를 실행한다.

로컬 원본은 `build --draft`로 처리한다. 새 AI 초안이 필요할 때만 `--codex`를 명시한다. 이 경로는 Codex에 제작 설명·스타일·배치 가이드를 전달한다. 스타일 PNG는 사용자가 전송 대상으로 선택한 파일만 `--style-reference`로 지정한다. API 키, 제3자 업체 업로드, 외부 제공자 폴백은 사용하지 않는다.

**검수와 수정**

- 장비 변형은 원본과 겹쳐 얼굴·몸·발 픽셀을 확인한다. 장비가 잘리면 장비 위치나 레이어를 수정하고 기준 캐릭터의 크기는 유지한다.
- 세트는 1×에서 식별성을 먼저 보고 4×에서 색·실루엣 차이를 찾는다. 예를 들어 도토리의 갓 색이나 등불 유리의 반사가 다르면 해당 항목의 제작 설명만 고쳐 새 번들에 만들고 다시 비교한다. 독립 생성과 한 아틀라스에서 잘라 낸 샘플은 출처를 구분한다.
- 걷기는 원래 속도로 마지막→첫 포즈의 연결과 접지를 본다. 타일은 3×3 반복에서 인공적인 선과 무늬를 확인한다. 이펙트는 불티와 투명 종료 프레임을 유지하고 1회 소멸·루프 경계를 실제 재생으로 확인한다.
- 결과는 새 출력 경로에 만들고 stdout의 파일 목록으로 전달한다. 기술 통과, 관찰한 외형, 엔진에서 확인한 범위를 구분한다. 사용자가 아트를 승인하면 해당 결과 파일과 리비전을 제작 기록에 연결한다. 승인 후 새로 만든 변형은 별도로 검토한다.

6동작은 승인된 기준 그림과 실제로 그린 동작 프레임을 사용한다. 동일 인물·공통 셀·피벗을 유지하고 루프의 접지, 공격의 접촉, 피격의 반동을 원속도에서 확인한다. 외부 비디오 생성기는 호출하지 않는다. pixelfx에서 만든 효과는 로컬 PNG·JSON·LICENSE·NOTICE를 입력으로 보존한다. 게임 스튜디오에서 호출하면 입력 지문, 제작과 검수, 씬 배치를 해당 프로젝트의 SSOT 그래프로 추적할 수 있다.
